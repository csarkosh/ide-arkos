# Emberwood

A small turn-based dungeon crawl for the terminal: one hero, a handful of rooms, and whatever
lives in them. Pure Python, no dependencies.

```bash
python3 -m game          # play
python3 -m unittest -q   # the tests
```

| Folder | What is in it |
|:---|:---|
| `game/` | the rules: combat, enemies, the map |
| `design/` | the design notes the rules are written from |
| `tests/` | one test file per rules module |
