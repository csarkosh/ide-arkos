# Effects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the watercolor spike as Arkos's effects feature: shader effects chosen in Settings, handed the theme's colours and the UI's blocks, with a documented contract, an `arkos effect` command set for agents, a measured GPU budget, and painted glyphs through a one-hook gpui fork.

**Architecture:** An effect is a folder (manifest, wash shader, optional glyph shader) loaded like a theme. The project window keeps `Option<ActiveEffect>`: a Metal layer under gpui's view drawn from the window's own timer with a `repr(C)` `Inputs` struct the preamble declares, built each frame by a pure `blocks` function over the layout and a highlight registry on `Root`. The app's own paint reads the manifest's alphas and text bump through `Root`. The gpui fork adds `Window::set_glyph_shader`; the ink glyph shader lives in Arkos.

**Tech Stack:** Rust, gpui 0.2.2 (forked at `https://github.com/csarkosh/gpui`), `metal` 0.29, objc2 AppKit, Metal Shading Language in `.metal` files, TOML manifests via serde.

**Spec:** `docs/superpowers/specs/2026-10-28-effects-design.md`. The spike it replaces is on this branch (`crates/arkos/src/effect.rs`, `crates/arkos/shaders/watercolor.metal`, `vendor/gpui`): read it for what works, keep none of its shape.

## Global Constraints

- Every transition uses `crates/arkos/src/motion.rs` and honours Reduce Motion: `HIGHLIGHT_ENTER` 250 ms / `HIGHLIGHT_EXIT` 200 ms for strokes, `THEME_FADE` 200 ms for an effect coming or going; `reduce_motion()` means a cut and no timer draws.
- Every colour is read from `root.theme` at paint time; the effect's inputs are built from the theme on every frame it draws.
- Shader code lives only in `.metal` files under `crates/arkos/effects/`, loaded with `include_str!` or read from the effects folder. No shader source in a Rust string.
- Builds: `nice -n 15 ~/.cargo/bin/cargo ...`, `jobs = 3` (the worktree's `.cargo/config.toml`), never `--release`, one cargo at a time. Finish each task with `cargo check --workspace --all-targets` warning-free.
- Tests headless (`cargo test -p arkos`), named as sentences, written before the code. A test that needs a Metal device checks `metal::Device::system_default().is_some()` and returns early with a note otherwise.
- `paper_alpha` floors at 0.5; the ink glyph shader keeps a stroke's core at 55% or more.
- Nothing speaks on stderr alone: a failure the user must see goes through `Root::show_notice`.
- Doc comments in plain prose, no em-dashes. `docs/guide.md`, `docs/agent-guide.md`, `docs/themes.md` and `docs/development.md` stay true at the end of every task that changes behaviour.
- The spike's switches (`ARKOS_EFFECT`, `ARKOS_INK`, `ARKOS_EFFECT_SHADER`, `GPUI_INK_GLYPHS`), its `SPIKE` comments and its thread-locals are gone by the end of Task 7.

## Review Focus

- A manifest with `highlights = "app"` under an effect, then a switch to None: the Explorer's selected row and the tab hover fill come back exactly as without an effect (Task 4's test `switching_to_none_restores_the_app_s_own_fills`).
- A wash or glyph shader that fails to compile: the window shows a notice naming the file and the compiler's line, draws the theme plain, and never crashes (Task 4's `a_shader_that_fails_to_compile_leaves_the_theme_plain_and_says_so`, Task 5's `a_glyph_shader_that_fails_to_compile_leaves_gpui_s_own_in_place`).
- Reduce Motion on: the timer draws only when the inputs changed, strokes are at their target at once, and a theme switch cuts (Task 4's `under_reduce_motion_the_wash_draws_only_when_something_changed`).
- A window resized while an effect is on: the layer's drawable follows the content view and the blocks follow the layout the same frame (Task 4's `blocks_follow_the_layout_and_the_drawable_follows_the_view`).
- The glyph shader must reach only the window that set it: the About window opened over Peach Light draws plain glyphs (Task 5's `the_glyph_shader_is_the_window_s_own`).
