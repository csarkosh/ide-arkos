# Tabular files as a grid: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `.csv`, `.tsv` or spreadsheet file opens in the viewer as a read-only grid (pinned
header and row numbers, zebra rows, numbers right-aligned, cell selection and TSV copy, find,
sheet tabs), with the code editor behind a "show raw" pill for delimited files.

**Architecture:** Two pure modules hold the model: `grid.rs` (decode, parse, sniff, column
kinds, selection, copy, find) and `workbook.rs` (calamine into the same `Book`). The viewer's
background load gains `Loaded.book`; the viewer keeps the book, the active sheet, a grid
selection and a grid scroll. `grid_view.rs` is a gpui element that paints only the visible rows
from a pure layout (widths, row range, hit testing, key moves), and `pane_view.rs` branches to
it when a book is shown. Nothing re-parses per keystroke: the book is built with the load and
on the Raw to Rendered switch.

**Tech Stack:** Rust, gpui 0.2.2 (the fork), `unicode-width`, `encoding_rs` (already in the
tree), `calamine` 0.38 (new), proptest (dev).

**Spec:** `docs/superpowers/specs/2026-11-03-csv-grid-design.md`

**Branch:** `csv-grid` in `.worktrees/csv-grid` (superpowers:using-git-worktrees; copy the
shared `target-dir` into its `.cargo/config.toml` as the other worktrees do).

## Global Constraints

- Builds: `nice -n 15 cargo ...`, never `--release`, one cargo at a time. Finish every task
  with `nice -n 15 cargo check --workspace --all-targets` showing zero warnings.
- Tests are headless, named as sentences, written before the code. Doc comments are prose. No
  em-dashes anywhere (code, docs, commits). Commits end with
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Colour: no new theme colours; every colour read from `root.theme` at paint time. Should one be
  needed, it goes through the contrast matrix and `arkos theme contrast` on all nine built-ins.
- Motion: nothing new animates; the grid's vertical scroll goes through the viewer's existing
  `ScrollAnimator`.
- Limits from the spec: `MAX_PLAIN_BYTES` (64 MB) unread; a sheet keeps at most
  `grid::MAX_ROWS` = 200,000 rows; `MEASURED_ROWS` = 200; `COLUMN_CAP` = 0.45 of the grid's
  width; a column's floor is three characters; `viewer::MAX_HITS` caps find.
- Sheet keys are `alt-cmd-]` and `alt-cmd-[` in a key context only a multi-sheet workbook sets.
- A workbook is never a document: no save, dirty mark, conflict or autosave.

## Review Focus

Inputs the spec implies but no section's tests name; each has its test in the task that owns it:

1. A file with lone `\r` line endings (an old Mac export): records must still split, not become
   one 50,000-cell row. Test in Task 1.
2. A cell of many kilobytes (a JSON blob in a column): the row stays one line, the cell is cut
   before shaping, and the frame never shapes the whole blob. Test in Task 4.
3. A sheet with thousands of columns (a workbook whose formatting extends the used range to
   column XFD): the grid keeps at most `grid::MAX_COLS` = 1,000 columns and the banner says how
   many were dropped, so measuring never walks 16,384 columns a frame. Test in Tasks 1 and 2.
4. UTF-16 without a byte order mark, or a binary renamed `.csv`: the binary notice, as today,
   never a panic or a grid of NULs. Test in Task 3.
5. A text file renamed `.xlsx`, or a zero-byte `.xlsx`: the unreadable notice with calamine's
   message, never a panic. Test in Task 2.

pub const MAX_ROWS: usize = 200_000;
pub const MAX_COLS: usize = 1_000;

impl Delimiter { pub fn byte(self) -> u8; }

pub enum Source { Delimited(Delimiter), Workbook }
pub struct Book { pub sheets: Vec<Sheet>, pub source: Source }
impl Sheet { pub fn cols(&self) -> usize; pub fn text(&self, cell: Cell) -> &str; pub fn cap(name: String, header: Vec<String>, rows: Vec<Vec<String>>) -> Sheet } // pads, drops past MAX_ROWS/MAX_COLS, infers kinds
pub fn is_delimited(path: &Path) -> bool;            // .csv, .tsv (case-insensitive)
pub fn decode(bytes: &[u8]) -> Cow<'_, str>;         // UTF-8 BOM stripped; UTF-16 LE/BE by BOM via encoding_rs; else UTF-8 lossy
pub fn sniff(text: &str, path: &Path) -> Delimiter;
pub fn parse(text: &str, delimiter: Delimiter, name: &str) -> Sheet;
pub fn column_kinds(header_len: usize, rows: &[Vec<String>]) -> Vec<ColumnKind>;
pub fn is_number(cell: &str) -> bool;
pub struct Cell { pub row: usize, pub col: usize }   // row 0 is the header
pub enum Scope { Cells, Columns, Rows, All }
pub struct Selection { pub anchor: Cell, pub head: Cell, pub scope: Scope }
impl Selection { pub fn cell(c: Cell) -> Self; pub fn rect(&self, sheet: &Sheet) -> (RangeInclusive<usize>, RangeInclusive<usize>); pub fn extend(&self, to: Cell) -> Self; pub fn move_by(&self, dr: isize, dc: isize, sheet: &Sheet) -> Self; pub fn contains(&self, c: Cell, sheet: &Sheet) -> bool; pub fn clamp(&self, sheet: &Sheet) -> Self; }
pub fn copy_text(sheet: &Sheet, sel: &Selection) -> String;
pub fn with_header(sel: &Selection) -> Selection;    // the rectangle with row 0 added
pub fn find(sheet: &Sheet, needle: &str) -> Vec<Cell>;
pub fn banner(sheet: &Sheet) -> Option<String>;      // "first 200,000 rows shown, 31,214 more in the file", "... and 24 columns past the 1,000th"
