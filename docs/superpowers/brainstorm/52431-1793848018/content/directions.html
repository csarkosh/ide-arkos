Timo Purple: three pixel-art directions

The game lives in the sidebar, the title bar, the tab bar and the gaps. The tab body stays plain Timo Purple so your work reads as it does today. All art is original, drawn at a low resolution and scaled up like a Game Boy Advance screen. Still frames: what moves is in each caption.

A. Overworld at dusk

The sidebar is a slice of a night landscape: a starry sky, a crescent moon, a far castle with cyan windows, pines and grass at the bottom. The tab bar is a stone ledge; the active tab is lit. Moving: stars twinkle, the castle's windows flicker now and then, a cloud drifts across the title bar, fireflies rise from the grass.

B. RPG menu windows

Every pane and bar is a classic bordered menu box with notched pixel corners, on a dithered purple ground. A pixel cursor points at the active tab and the selected file. Moving: the cursor bobs, a glint runs along a box's border when it gets focus, and the ground's gradient shimmers slowly.

C. Crystal dungeon

The ground is a stone wall of violet bricks. Torches with cyan magic flames line the sidebar, and the tab bar is a carved lintel set with gems; the active tab's gem glows. Moving: flames flicker, sparkles drift up from them, and a busy Claude session's gem pulses.
