Doctor Icon Candidates

Each row below is the Arkos title bar at its real size, with the bell and one candidate for the doctor. Every glyph is a 16 px box, 1.5 px stroke, the same as the bar draws. Reply with the letter you want; the cards underneath show the same glyph larger on both chrome tones.

In the bar, actual size

Closer look

A, B and C are stethoscopes drawn three ways. D to H are cross and heart shapes. I to N are other medical instruments. O and P are non-medical "fix it" shapes, in case the doctor should not read as medical at all. All are strokes only, so the bar can draw the chosen one with the same path code it uses today.
